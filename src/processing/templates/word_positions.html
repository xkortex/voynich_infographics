The default uses a separate vertical scale for every symbol, like the supplied reference: compare position shapes, and use the percentages and colors to compare frequency. Switch to “Shared count scale” to compare absolute counts. Sort alphabetically or by descending frequency. The ridgeline layout uses opaque overlapping areas; reduce ridge spacing for more overlap. Both download buttons capture the current units, scale, order, layout and spacing. PNG exports use up to 2× resolution. For Forme and Orationum, the full editions use the same word extraction as the word-length chart. Editorial material and Latin OCR noise remain. Letter case is folded; accents, ligatures and historical letters are retained; apostrophes are excluded from letter positions. EVA grouping applies only to Voynich. All data and vector glyphs are embedded; the default chart works without JavaScript.
