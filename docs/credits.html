Comparison texts

The word-length comparison uses Project Gutenberg ebook 8102, The Forme of Cury, and user-supplied OCR from Corpus orationum, CCSL 160 (A–C). Only aggregate word-length counts and chart graphics are included here; the supplied text files are not redistributed.

Continuous reading edition

The reader publishes transformed per-folio text from the Voynichese Project XML, not ZL3b. The supplied XML carries Copyright © 2014 The Voynichese Project and an Apache 2.0 notice. Its text, word order and indices are retained; image coordinates are omitted. See the reader’s notice, license and source fingerprints. No XML originals, scans or font binary are bundled; the derived text is published specifically for reading.
