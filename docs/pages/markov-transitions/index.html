How the model is counted

First order: P(next | previous unit). Second order: P(next | previous two units). In second order, choosing a destination shifts the state from (a,b) to (b,next). Each edge is an observed count divided by the total outgoing count for its context. There is no smoothing or automatic backoff.

Starting: Reset leaves the text empty. The first choice uses empirical first-unit counts at the start of readable runs. Second order uses empirical run-initial pairs for the second choice, then ordinary second-order transitions. If a context has no observed successor, generation stops; use Undo or Reset. End-of-run observations are not a separate stop state, so these probabilities are conditional on an observed next unit.

Spaces and boundaries: Count complete basic-EVA words in each IVTFF text locus (line or label), separated by exactly one space. Periods, commas and drawing intrusions are treated as word separators. Angle-bracket annotations are removed. Reject an entire word with alternatives, extended codes, ligature braces or unreadable markers and break the run there. Never bridge an unreadable gap or concatenate independent loci; no leading or trailing space is inserted. This boundary policy differs from the folio-based analyses elsewhere on the site.

Units: Grouped mode treats cfh, ckh, cph, cth, ch and sh as single units using longest match. Letter mode uses the individual EVA letters. Spaces are included in both. First/second order refers to these selected units, not an assumed phonetic character.

Sources: ZL3b, IT2a, VT0e and RF1b basic EVA are related resources. IT/VT share Takahashi ancestry; RF combines readings. Differences can reflect coverage, word boundaries and transcription conventions. This is generated text, not an excerpt or a translation of the manuscript. Glyph labels reuse the atlas’s embedded EVA outlines by Gabriel Landini; see glyph and source credits.

Lexicon highlighting: Exact whole-word matches are checked against the selected transcription’s accepted words. A space (or a model dead end) completes a generated word. A matching unfinished word gets a dotted outline because it may continue. Matches link to a source-folio spelling candidate in Voynichese; the live transcription may differ. This marks corpus membership, not a translation or meaningful phrase.

The random button samples proportional to the full integer counts using the browser’s random-number generator. Clicking a node makes a deliberate choice rather than a random sample. Copy always copies ordinary spaces, regardless of their visible display.
